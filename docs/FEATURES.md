# GTA 5 Mod Menu — feature reference

Use the GTA 5 mod menu workspace to move between module groups, keybinds, and player presets. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Module groups | Content and resource groups, together with their configuration or organization details. |
| Keybinds | Shortcut assignments and control mappings, organized in one reference section. |
| Player presets | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
